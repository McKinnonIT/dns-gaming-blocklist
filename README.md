# dns-gaming-blocklist

A plain-text list of domains classified as gaming sites, one per line, for use as a Technitium DNS Server block list URL.

Generated and updated weekly by [dns-domain-classifier](https://github.com/McKinnonIT/dns-domain-classifier) - do not edit `games.txt` by hand, changes will be overwritten.

Point Technitium's block list config at:
`https://raw.githubusercontent.com/McKinnonIT/dns-gaming-blocklist/main/games.txt`
